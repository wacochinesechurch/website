# Sermons

**This folder is intentionally empty.**

The old site’s Sermons page listed no sermons at all — just two plain-text
links, one of which advertised a weekly "Sunday 10:45 am live stream" that was
in fact a fixed recording from 17 September 2023.

Inventing sermon titles, speakers or dates would be fabricating the teaching of
a real congregation, so nothing has been added. The indexed archive on
/sermons — speaker, date, passage, series, bilingual, with YouTube embeds — is
fully built and renders the moment the first entry is added here.
