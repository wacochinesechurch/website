# Leaders

**This folder is intentionally empty.**

No pastor, elder or leader is named anywhere in Waco Chinese Church's public
material — only website and poster volunteers in the old site's footer, and
three fellowship contacts. Rather than invent a leadership structure, the
Leadership section on the About page is fully built but does not render while
this folder has no entries.

Add a person here (via /admin or as a Markdown file) and the section appears.
`draft` defaults to `true` on purpose, so a real person's name is never
published by accident.
